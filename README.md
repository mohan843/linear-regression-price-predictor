# Linear Regression Price Predictor

A simple machine learning project using Scikit-Learn to predict prices (e.g., house prices) based on a single feature (size) using Linear Regression.

## Features
- Synthetic dataset generation.
- Model training using `LinearRegression`.
- Evaluation with MSE and R2 Score.
- Sample prediction capability.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script: `python main.py`
